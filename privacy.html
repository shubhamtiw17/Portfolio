Privacy Policy

faceless-pipeline · Last updated: 7 November 2026

1. Who we are

faceless-pipeline ("the app") is a private, single-user tool operated by Shubham Tiwari (contact: moneyexposed09@gmail.com). Its only user is its owner, who uses it to upload videos to the owner's own YouTube channels.

2. Use of YouTube API Services

The app uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (https://policies.google.com/privacy).

3. Information the app accesses

  • OAuth tokens for the owner's own YouTube channels, granted through Google's consent screen with the scopes youtube.upload and youtube.
  • Basic channel information (channel name and ID) of the owner's own channels, read only to confirm the correct channel.
  • Upload results: the IDs of videos the app uploaded.

The app does not access, collect or process data of viewers, subscribers, commenters or any other YouTube users.

4. How information is used

Solely to upload and schedule the owner's own videos and set their thumbnails. No information is used for advertising, profiling, analytics or sold to anyone.

5. Storage and security

OAuth tokens are stored as encrypted secrets in the owner's private GitHub repository and on the owner's own computer. Uploaded video IDs are stored in a private log. No other YouTube API data is stored.

6. Sharing

No information obtained from YouTube API Services is shared with any third party. Videos are sent only to YouTube.

7. Cookies and device data

The app has no public interface and does not store or read cookies or any information on users' devices.

8. Data retention and deletion

  • Stored data is kept only while the app is in use.
  • Authorized data is deleted within 7 days if access is revoked, and stored YouTube API data is refreshed or deleted at least every 30 days.
  • Access can be revoked at any time on the Google security settings page (https://security.google.com/settings/security/permissions). Revoking immediately stops all access.
  • To request deletion of any stored data, email moneyexposed09@gmail.com; it is deleted within 7 days.

9. Changes

Changes to this policy are posted on this page with a new date.
